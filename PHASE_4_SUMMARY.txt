🎓 USAGE PATTERNS
═══════════════════════════════════════════════════════════════════════════════

Basic Scene Creation:
  1. Open SceneBuilderProV4
  2. Enter scene name and duration
  3. Set fade in/out times
  4. Configure DMX properties
  5. Save scene

Creating Complex Effects:
  1. Click "⚡ Effects" button
  2. Open AdvancedEffectBuilder
  3. Select effect type (Color/Chaser/Move/Value/Curve)
  4. Choose waveform type
  5. Adjust Speed/Phase/Amplitude/Offset
  6. Select target fixtures/channels
  7. Choose blend mode
  8. Apply effect

Building Cue Sequences:
  1. Click "📋 Cues" button
  2. Open CueSequenceBuilder
  3. Add cues by clicking "+ Cue"
  4. Drag to reorder cues
  5. Set duration per cue
  6. Configure fade in/out
  7. Select trigger mode
  8. Apply sequence

Configuring Channels:
  1. Click "⚙️ Channels" button
  2. Open ChannelConfigurator
  3. Select fixture type (PAR/Moving Head/etc.)
  4. Click preset to auto-populate
  5. Customize as needed
  6. Save configuration

  • Deploy to lightforge
